# AntiGravity AI — Features & User Guide

## 1. Grounded PDF Workspace Reader
- Split-screen workspace layout.
- Left side: High-performance PDF renderer with multi-color highlight annotations and clickable citation boxes.
- Right side: Interactive AI Assistant capable of answering paper-specific questions with exact page references.

## 2. Multi-Paper Literature Review & Comparison Matrix
- Select up to 10 research papers.
- Auto-generate comparison matrix tables across key dimensions:
  - Dataset / Benchmark
  - Core Algorithm / Model Architecture
  - Quantitative Metrics (Accuracy, F1, BLEU, Latency)
  - Methodological Limitations & Future Work

## 3. Interactive Citation Network Graph
- Visual node-edge graph powered by `React Flow`.
- Integrated with Semantic Scholar API & OpenAlex API to visualize paper influence, co-citations, and reference trees.

## 4. Academic Productivity Suite
- **Flashcard & Quiz Generator**: Automated extraction of active recall flashcards with variable difficulty.
- **Hierarchical Mind Maps**: Structural visual trees summarizing paper methodologies.
- **Code Extractor**: Convert paper pseudocode into executable Python / C++ boilerplate scripts.
